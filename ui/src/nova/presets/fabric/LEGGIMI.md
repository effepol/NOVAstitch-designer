# Preset tessuto (modulo e)

Un file per preset: `<id>.json`, secondo lo schema `../fabric-preset.schema.json`.
Un file rifiutato all'avvio non blocca gli altri; l'errore cita file e campo.

I valori vengono dal contratto e dal libro Punch: nessun valore inventato.
I file arrivano quando l'Architetto ha dato i valori mancanti.
